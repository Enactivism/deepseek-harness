# Agent Note: Qt 外壳系统托盘窗口生命周期

Status: implemented

[English](2026-09-29-qt-system-tray-window-lifecycle.md) | 中文

## Problem

关闭 Qt 外壳窗口会终止它持有的 Harness 服务，因此用户无法在暂时移除桌面界面的同时保留本地服务运行。

## Decision

`HarnessWindow` 持有一个 `QSystemTrayIcon`，使用程序生成的 `DH` 图标，并提供包含“打开”和“关闭”的上下文菜单。双击托盘图标会恢复并激活主窗口。系统托盘可用时，普通主窗口关闭只会隐藏主工作区，忽略关闭事件，并保持桌宠、桌宠聊天窗口以及 Harness 服务运行。托盘菜单中的“关闭”和“文件 > 退出”会设置显式退出标记，关闭窗口，隐藏所有辅助窗口和托盘图标，并停止由外壳持有的服务。桌面环境没有系统托盘时，关闭事件保留直接退出行为，避免进程变得无法访问。

## Alternatives considered

**保留当前的直接关闭行为。** 不采用，因为关闭工作区也会终止本地服务，用户无法从托盘快速恢复。

**在 Web UI 中实现托盘。** 不采用，因为托盘图标和进程退出属于原生 Qt 外壳，窗口隐藏后仍必须可用。

**将桌宠和聊天窗口与主窗口一起隐藏。** 不采用，因为桌宠是独立的用户窗口；关闭工作区不应停止它的指针追踪或打断交互。

## Consequences

外壳隐藏时 Harness 服务继续运行，因此重新打开不会重启本地服务。原生外壳使用小型程序生成图标，无需增加平台专用资源或资源构建目标。没有可用系统托盘的环境回退到原有的直接关闭行为。
